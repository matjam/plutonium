# Package documentation verification, native Linux amd64

Status: complete. Roadmap item 93 implements sections 1.1, 18.1 and appendix F.
The debug allocator's package-variable reporting remains the next ordered smaller item.

## Behavior and exact oracles

`pluto doc [package-or-directory] [symbol[.method]]` loads an ordinary package without requiring
`main`, linking foreign declarations or executing initializers. The package defaults to `.`.
Source can come from the embedded library, PLUTOROOT, a directory or an import path inside the
current module. `-all` includes private declarations; an explicit symbol may name a private
declaration. `-mode` selects hosted, freestanding or kernel source, and `-tags` adds build tags.
Successful documentation exits 0, source and missing-symbol errors exit 1, and usage errors exit 2.

The renderer preserves source comments, aliases, generics, owner constraints, enums, unions,
default parameter expressions and receiver declarations, while omitting function bodies.
Constant values are resolved, including implicit declarations in an iota group. Specific leading
or trailing comments take precedence over a group's fallback comment. Type queries include
methods; method queries follow checked aliases, pointer aliases, promoted methods and imported
aliases to the original source object. A generic instance shows its original declaration with
defaults and a separately labeled substituted signature. Shared source ASTs remain unchanged.

The exact labels are `value`, `view`, `owner (moves)` and `counted`, using section 8.7's precedence:
owner, view, counted, value. Strings, maps, channels, shared/synced boxes and weak references are
counted. Ordinary interfaces, including Error interfaces, remain statically views; section 16.7's
dynamic counting does not replace their static kind. Owner marks are explicit, never inferred
from a method named Drop. The same cycle-safe classifier serves documentation, hovers, completion
and document symbols, with no depth cutoff. Hover explanations account for weak references and
aggregates that combine borrowed and counted fields.

Twenty-seven exact CLI goldens cover listings, private names, symbols, methods, generic instances,
aliases, promotions, imported methods, interface comments, grouped comments, source modes, tags,
module paths, help and errors. A source fixture has a panicking initializer and an unavailable
foreign binding; documentation succeeds without executing or linking either. `_test.p` names
are excluded. Separate exact tests distinguish embedded source from a custom PLUTOROOT. Classifier
tests cover every kind, alias and generic ownership, mixed aggregates, recursive pointer types,
64 nested arrays and incomplete editor types with an ordinary Drop method. LSP fixtures now
declare their owners correctly and fail on type errors. Source immutability, repeatable output
and writer failures are checked independently.

## Failed-run evidence

Initial compilation exposed the two remaining LSP callers of the removed local classifier;
both now use the shared helper. Existing hover fixtures had omitted owner marks and were
corrected to valid declarations. The checker rejects an ordinary source type with a Drop
method, so the no-inference test instead constructs an incomplete editor type after checking
a valid package. An initial embedded bits comment expectation was corrected against that
package's actual source documentation. One combined focused invocation incorrectly passed
the CLI-only `-update` flag to packages that do not define it; that failure is preserved in
`focused-initial.log`, and subsequent focused invocations use the proper package flags.

Review added checked method identity resolution, explicit instantiated signatures,
declaration-specific trailing comments and truthful hover explanations. Final peer and root
reviews are clear. No full acceptance gate failed, and no specification rule, oracle, timeout
or resource cap was weakened. No language chapter changed.
